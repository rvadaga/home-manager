# codex model and reasoning

use `gpt-6-astra` for codex sessions and authorized subagents. use `medium` reasoning for routine work with a clear scope. use `xhigh` for research, work whose scope is still being determined, or complex substantive problems. choose the effort for the assigned work; being a subagent or using plan mode alone does not require `xhigh`.

apply this choice when selecting settings for a new session or spawning an authorized subagent. when continuing a session, use a supported model or effort control if one is available. if the needed setting cannot be changed through the available controls, say which setting is needed; instructions alone do not change the running model or effort. this rule does not authorize creating agents, resuming tasks, or messaging other sessions.
